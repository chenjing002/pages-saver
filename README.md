# Pages Saver (Chrome extension)

Select an area of a page, save it as a PNG, click the site's "next page" button, wait, and repeat N times.

## Install
1. Open `chrome://extensions`, turn on **Developer mode**.
2. Click **Load unpacked** and choose this folder.

## Use
1. Open the website, go to the first page you want.
2. Click the extension icon → **1. Select area** → drag a rectangle on the page.
3. Click the icon → **2. Pick next button** → click the site's next-page button once (it is only remembered, not pressed).
4. Set **Pages to save** and **Wait after click** (default 6 s), then **Start**.
5. Images go to `Downloads/pages-saver/page_001.png`, `page_002.png`, ...

Keep the tab visible and don't scroll or resize the window while it runs. Click the icon → **Stop** to stop early.
